# Hearth wear estimation (working title)

Simulation-based study: physics-informed estimation of blast furnace hearth refractory
thickness and protective skull thickness from thermocouple readings, with a focus on
robustness to thermocouple failure.

**Data note:** all hearth data in this repository is SIMULATED from a heat-transfer model.
Real blast furnace process data (Mendeley) is used only to drive operating conditions and
to estimate sensor noise/dropout behaviour. Nothing here has been validated on a real furnace.
